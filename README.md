# Tauranga Classic Motorcycle Club Website

GitHub Pages-ready version of the TCMCC website prototype.

## Publish on GitHub Pages

1. Create a new **public** GitHub repository, for example `tcmcc-website`.
2. Upload everything in this folder to the top level of the repository.
3. Commit the files.
4. Open **Settings → Pages** in the repository.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. GitHub will show the public website address after deployment completes.

## Main files

- `index.html` — website homepage and current single-page site.
- `assets/tcmcc-badge.png` — club badge used in the header.
- `.nojekyll` — tells GitHub Pages to serve the site as plain static files.

## Updating the site

Future photos, newsletters and documents can be placed in subfolders such as `assets/`, `newsletters/` and `archives/`, with links added to `index.html`.
